# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/gohead-cms/gohead/security/advisories/new).
Do not open a public issue.

Fixes land on `master` and in the next release. See the
[security page](https://gohead-cms.github.io/gohead/operations/security/) of the handbook for
hardening guidance and how to verify signed images.
