# User manual

A step-by-step guide to the GoHead admin UI, feature by feature, with screenshots. It is
written for the people who use GoHead every day: editors, writers and administrators. For
APIs, configuration and deployment, see the rest of the handbook.

The screenshots come from a GoHead set up with the [Next.js starter](../frontend/nextjs.md)'s
blog: articles, authors and categories in English and French.

| Page | For | You will learn to |
|------|-----|-------------------|
| [Getting started](getting-started.md) | everyone | sign in, find your way around, read the dashboard |
| [Content model](content-model.md) | admins | create collections, single types and components, and their fields |
| [Editing content](editing-content.md) | editors, writers | create, edit, translate, publish entries; compare and restore versions |
| [Media library](media.md) | editors | upload and organize images and files |
| [Users and roles](users-and-roles.md) | admins | invite people, give them the right permissions, open content to the public |
| [API tokens](api-tokens.md) | admins | give a website or a script access to the API |
| [Webhooks](webhooks.md) | admins | notify other services (a website, Slack) when content changes |
| [Locales](locales.md) | admins | add languages |
| [Agents](agents.md) | admins | let AI agents summarize, tag, moderate or translate content |
| [Approvals](approvals.md) | editors | review the changes agents propose |
| [Activity](activity.md) | admins | follow agent runs, their cost, and every content change |

!!! tip "What you see depends on your role"
    Viewers read content; editors also write, publish and manage media; admins see
    everything, including the content model, agents and settings. Custom roles sit in
    between: see [Users and roles](users-and-roles.md).
